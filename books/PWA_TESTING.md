# نظرة 🧿 — دليل الاختبار اليدوي (PWA_TESTING)

دليل لمختبِر بشري على جهاز حقيقي. كل خطوة: ما تفعله، ثم النتيجة المتوقعة، ثم مربّع ✓.

## التشغيل المحلي

افتح تركس واكتب:

```bash
cd preview
python -m http.server 8766 --bind 127.0.0.1
```

ثم افتح في المتصفح: `http://127.0.0.1:8766/`

ملاحظات:
- على جهاز آخر بنفس الشبكة، استخدم IP الحاسوب بدل localhost.
- بلاطات الخريطة تأتي من CDN (إنترنت مطلوب أول مرة). الديمو نفسه يعمل بلا شبكة.
- الكود وحدات ES modules تحت `lib/`. لا يعمل عبر `file://` مباشرة — لازم خادم HTTP.

## الخطوات

### 1) شاشة الترحيب
افتح الرابط.
- [ ] شعار العين + «نظرة 🧿» + زرّان (الموقع / الديمو) ظاهران، والكونسول بلا أخطاء.

### 2) الخريطة والعداد
اضغط «شغّل الموقع» ووافق على صلاحية الموقع.
- [ ] الرئيسية تظهر بخريطة داكنة وعلامات الكاميرات (🛑💡🚨🐢📏) والعداد يعمل.

### 3) الديمو
ارجع بزر ↩︎ ثم اضغط «ديمو: قيادة على شارع المطار».
- [ ] المركبة تتحرك كل 1.4 ثانية والعدد يقفز (60–90) ويظهر خط مسار أزرق.
اضغط «⏹ إيقاف الديمو».
- [ ] المسار الأزرق يزول وتتوقف الحركة.

### 4) دخول الممر
أول نقطة في الديمو هي دخول ممر المطار.
- [ ] يظهر صوت «دخلنا ممر سرعة» (أو الصيغة الفصحى إذا فعّلت «عربي محكي»)، وبطاقة زرقاء فيها: الحد، متوسطك، المتبقي، وشريط التقدّم.

### 5) خروج الممر
أكمل الديمو حتى نقطة الخروج.
- [ ] تظهر بطاقة الحكم: «تم بالمتوسط <رقم> — الحد <رقم>» كإشعار، والبطاقة الزرقاء تبقى 6 ثوانٍ ثم تخفى.
ملاحظة: في الديمو المتوسط يظهر «0» لأن المسافة القصيرة جداً؛ في القيادة الحقيقية الرقم حقيقي.

### 6) تنبيهات الكاميرات
راقب البطاقة الحمراء/الوردية أثناء الديمو.
- [ ] التنبيه يتصاعد: 500 م ثم 300 م ثم 150 م ثم «الكاميرا هنا» — كل مرحلة مرة واحدة مع نغمة.
- [ ] نفس الكاميرا لا تُنغّم ثانية قبل 45 ثانية.

### 7) شريط المجاملة
عندما لا يوجد تنبيه نشط، شريط صغير أعلى البطاقات.
- [ ] يعرض «حد <رقم> · بعد <مسافة> <نوع الكاميرا>»، ويختفي أثناء التنبيه النشط.

### 8) القائمة والبحث والفلاتر
افتح زر 🧭 أو «كل الكاميرات».
- [ ] الفلاتر (الكل / متوسط / رادار / إشارة / ضبطة / مطبّ) تصنّف فوراً؛ البحث يعمل (جرّب Airport)؛ القائمة غير فارغة عند فتحها.

### 9) البلاغ
اضغط 📡 بلاغ، اختر نوعاً، أرسل.
- [ ] يظهر إشعار «بلاغك وصل» + صوت شكر، ويُخزَّن محلياً في localStorage (مفتاح nz_reports).

### 10) الإعدادات
- [ ] غيّر «الحد فوق بـ» إلى 5 وحدّث الصفحة: القيمة محفوظة.
- [ ] اختر «بلا صوت» ثم أعد الديمو: لا نغمة ولا كلام إطلاقاً.
- [ ] «أعرض متوسّطك أثناء السير» مطفأة: تبقى خانة المتوسط فارغة أثناء السير، لكن القيمة النهائية تظهر بعد نهاية الممر.

### 11) الممر ينبّه قبل 200 م + الخصوصية
- [ ] عند الاقتراب من ممر، إشعار «ممر … بعد 200 م» يظهر مرة واحدة لكل ممر في الجلسة.
- [ ] «أوقف الموقع والصفحة مقفلة» مفعل: انتقل لتطبيق آخر فيختفي مؤشّر الموقع، ويعود عند العودة. (لا يعمل أثناء الديمو).

### 12) الأوفلاين والتثبيت
- [ ] حمّل الموقع مرة، ثم اجعله طيران وأعد التحميل: كل شيء يعمل (الواجهة + بيانات الكاميرات + الديمو).
- [ ] من كروم/إيدج: أيقونة «تثبيت» في شريط العنوان → التطبيق يفتح بنافذته المستقلة.

## حدود معروفة (للتوثيق الصريح)

- «شارك بلاغاتي مع الجماعة»: غير موصول بالسماء بعد — البلاغات محلية فقط.
- iOS/Safari: التثبيت يتم عبر «إضافة إلى الشاشة الرئيسية» وليس شريط العنوان، وقد لا يعمل الاهتزاز.
- المسافة «المتبقّي» حساب خط مستقيم إلى نقطة خروج الممر.
